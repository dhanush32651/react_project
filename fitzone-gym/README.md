# FitZone Gym - React Website

Pages: Home, Programs, Trainers, Pricing, BMI Calculator, Gallery, Contact.

## Run
```
npm install
npm run dev
```
Open http://localhost:5173

## Your images
Put your photos in `src/assets/images/` using these names (any size, .jpg):

hero.jpg, about.jpg, program-strength.jpg, program-cardio.jpg, program-yoga.jpg,
program-crossfit.jpg, trainer-1.jpg, trainer-2.jpg, trainer-3.jpg, gallery-1.jpg ... gallery-6.jpg

The folder currently has coloured placeholders so the site works immediately.
